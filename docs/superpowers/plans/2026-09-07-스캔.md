# 스캔(Scan) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 브라우저에서 종이를 카메라로 찍어 네 모서리를 자동 인식하고 반듯하게 편 뒤, 필터를 골라 이미지 또는 PDF로 저장하는 한 페이지짜리 웹 앱을 만들어 깃허브 페이지로 배포한다.

**Architecture:** 정적 파일만 사용하는 클라이언트 전용 앱. `index.html` 하나에 HTML·CSS·JS를 모두 담는다(빌드 단계 없음). 이미지 처리는 CDN에서 불러온 OpenCV.js + jscanify로, PDF 생성은 jsPDF로 한다. 상태 기계(`loading → camera → adjust → export`)로 화면을 전환한다. 순수 함수(기하 계산·필터)는 `window.scanDebug`에 노출해 Playwright에서 직접 호출·검증한다.

**Tech Stack:** 바닐라 JS(ES2020), OpenCV.js 4.10.0, jscanify 1.4.0, jsPDF 2.5.2, 테스트는 `@playwright/test`(Chromium), 로컬 정적 서버는 Node 내장 `http` 모듈 스크립트.

**Spec:** `docs/superpowers/specs/2026-09-07-스캔-design.md`

## Global Constraints

- 서버 없음. 모든 처리는 브라우저 안에서. 사진을 외부로 전송하는 코드를 절대 넣지 않는다.
- AI API 키·유료 서비스 사용 안 함.
- 앱 본체는 **단일 파일 `index.html`**. 외부 JS는 CDN 3개만.
- 라이브러리 버전 정확히 고정: `opencv.js` **4.9.0** (`https://docs.opencv.org/4.9.0/opencv.js` — 4.10.0은 docs.opencv.org에 미발행, Task 2에서 확인·변경. `cv`는 thenable이지만 절대 `await`하지 말 것: 헤드리스에서 멈춤. `cv.Mat`가 함수가 되는 시점으로 준비 판정. opencv.js는 페이지 `load` 이후 동적 삽입), `jscanify` **1.4.0** (`https://cdn.jsdelivr.net/npm/jscanify@1.4.0/src/jscanify.js`), `jspdf` **2.5.2** (`https://cdn.jsdelivr.net/npm/jspdf@2.5.2/dist/jspdf.umd.min.js`, 전역 `window.jspdf.jsPDF`).
- UI 문구는 쉬운 한국어. 개발용 별명·비유 금지(예: "워프"·"컨투어" 같은 단어를 화면에 쓰지 않는다). 전문어가 꼭 필요하면 풀어서.
- 워프 결과 캔버스 긴 변 ≤ 2000px. 검출·워프 입력 이미지는 긴 변 ≤ 3000px로 축소한 사본 사용.
- 페이지 수 소프트 상한 20장(넘으면 경고만, 막지 않음).
- 모든 `cv.Mat`은 사용 직후 `.delete()`. 반드시 `withMats()` 헬퍼로 감싼다.
- 아이폰 사파리 대응: `<video>`에 `playsinline muted autoplay` 필수, `getUserMedia`는 `facingMode: { ideal: 'environment' }`.

## Testing Strategy (읽고 시작할 것)

- 테스트 러너는 **Playwright 하나**. 순수 함수도 `page.evaluate(() => scanDebug.geometry.outputSize(...))` 로 브라우저 안에서 호출해 검증한다(별도 node 단위 러너 없음).
- Playwright는 Chromium을 `--use-fake-device-for-media-stream --use-fake-ui-for-media-stream` 로 띄운다 → `getUserMedia`가 합성 영상으로 자동 허용됨. 카메라 "거부" 시나리오는 `context.route` 로 스크립트 주입해 `navigator.mediaDevices.getUserMedia` 를 거부하도록 덮어써서 테스트한다.
- 종이 검출·워프·필터 테스트는 **파일 선택 경로**로 `tests/fixtures/paper-on-desk.jpg` 를 `<input type=file>` 에 주입해서 한다(합성 카메라 영상에는 종이가 없음).
- OpenCV 로딩이 느리므로 cv 준비 대기는 최대 40초. `test.setTimeout(60000)` 를 spec 파일 상단에 둔다.
- 각 Task는 "테스트 먼저 → 실패 확인 → 구현 → 통과 확인 → 커밋" 순서.

실행 명령:
- `npm test` → `playwright test`
- `npm run fixture` → 합성 사진 재생성
- `npm start` → `node tests/server.mjs` (수동 확인용, http://localhost:4173)

```js
import http from 'node:http';

import path from 'node:path';

const root = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..');
const TYPES = {
  '.html': 'text/html; charset=utf-8',
  '.js': 'text/javascript; charset=utf-8',
  '.mjs': 'text/javascript; charset=utf-8',
  '.json': 'application/json; charset=utf-8',
  '.css': 'text/css; charset=utf-8',
  '.jpg': 'image/jpeg',
  '.png': 'image/png',
};

const server = http.createServer((req, res) => {
  const url = decodeURIComponent(req.url.split('?')[0]);
  const rel = url === '/' ? '/index.html' : url;
  const file = path.join(root, rel);
  if (!file.startsWith(root)) { res.writeHead(403); res.end('403'); return; }
  fs.readFile(file, (err, data) => {
    if (err) { res.writeHead(404); res.end('404'); return; }
    res.writeHead(200, { 'content-type': TYPES[path.extname(file)] || 'application/octet-stream' });
    res.end(data);
  });
});

const port = process.env.PORT || 4173;
server.listen(port, () => console.log(`serving ${root} on http://localhost:${port}`));
```

```js
/* ===== geometry ===== */
function _dist(a, b) { return Math.hypot(a.x - b.x, a.y - b.y); }

function orderCorners(pts) {
  const bySum = [...pts].sort((a, b) => (a.x + a.y) - (b.x + b.y));
  const byDiff = [...pts].sort((a, b) => (a.x - a.y) - (b.x - b.y));
  return {
    topLeft: bySum[0],
    bottomRight: bySum[3],
    bottomLeft: byDiff[0],
    topRight: byDiff[3],
  };
}

function isConvexQuad(c) {
  const p = [c.topLeft, c.topRight, c.bottomRight, c.bottomLeft];
  let sign = 0;
  for (let i = 0; i < 4; i++) {
    const a = p[i], b = p[(i + 1) % 4], d = p[(i + 2) % 4];
    const cross = (b.x - a.x) * (d.y - b.y) - (b.y - a.y) * (d.x - b.x);
    if (Math.abs(cross) < 1e-6) return false;
    const s = Math.sign(cross);
    if (sign === 0) sign = s;
    else if (s !== sign) return false;
  }
  return true;
}

function outputSize(c) {
  let w = Math.round(Math.max(_dist(c.topLeft, c.topRight), _dist(c.bottomLeft, c.bottomRight)));
  let h = Math.round(Math.max(_dist(c.topLeft, c.bottomLeft), _dist(c.topRight, c.bottomRight)));
  const longEdge = Math.max(w, h);
  if (longEdge > 2000) {
    const k = 2000 / longEdge;
    w = Math.round(w * k); h = Math.round(h * k);
  }
  return { w, h };
}

function mapPoint(p, from, to) {
  return {
    x: to.x + (p.x - from.x) / from.width * to.width,
    y: to.y + (p.y - from.y) / from.height * to.height,
  };
}
```

```js
function withMats(fn) {
  const bag = [];
  const track = (m) => { bag.push(m); return m; };
  try { return fn(track); }
  finally { for (const m of bag) { try { m.delete(); } catch (e) {} } }
```

```js
function _canvasOut(mat, w, h) {
  const c = document.createElement('canvas'); c.width = w; c.height = h;
  cv.imshow(c, mat);
  return c;
}

function fGray(src, track) {
  const g = track(new cv.Mat());
  cv.cvtColor(src, g, cv.COLOR_RGBA2GRAY);
  const out = track(new cv.Mat());
  cv.cvtColor(g, out, cv.COLOR_GRAY2RGBA);
  return out;
}

function fBw(src, track) {
  const g = track(new cv.Mat());
  cv.cvtColor(src, g, cv.COLOR_RGBA2GRAY);
  const bin = track(new cv.Mat());
  cv.adaptiveThreshold(g, bin, 255, cv.ADAPTIVE_THRESH_GAUSSIAN_C, cv.THRESH_BINARY, 15, 10);
  const out = track(new cv.Mat());
  cv.cvtColor(bin, out, cv.COLOR_GRAY2RGBA);
  return out;
}

function fAuto(src, track) {
  const rgb = track(new cv.Mat());
  cv.cvtColor(src, rgb, cv.COLOR_RGBA2RGB);
  const gray = track(new cv.Mat());
  cv.cvtColor(rgb, gray, cv.COLOR_RGB2GRAY);
  // 배경 밝기 추정: 큰 커널 블러
  let kk = Math.max(3, Math.round(src.cols / 8)); if (kk % 2 === 0) kk += 1;
  const bg = track(new cv.Mat());
  cv.GaussianBlur(gray, bg, new cv.Size(kk, kk), 0);
  const grayF = track(new cv.Mat()); gray.convertTo(grayF, cv.CV_32F);
  const bgF = track(new cv.Mat()); bg.convertTo(bgF, cv.CV_32F);
  cv.add(bgF, new cv.Mat(bgF.rows, bgF.cols, bgF.type(), new cv.Scalar(1)), bgF);
  const norm = track(new cv.Mat());
  cv.divide(grayF, bgF, norm, 255);
  const norm8 = track(new cv.Mat()); norm.convertTo(norm8, cv.CV_8U);
  // 대비 스트레치
  cv.normalize(norm8, norm8, 0, 255, cv.NORM_MINMAX);
  // 살짝 선명화
  const blur = track(new cv.Mat());
  cv.GaussianBlur(norm8, blur, new cv.Size(0, 0), 3);
  const sharp = track(new cv.Mat());
  cv.addWeighted(norm8, 1.5, blur, -0.5, 0, sharp);
  const out = track(new cv.Mat());
  cv.cvtColor(sharp, out, cv.COLOR_GRAY2RGBA);
  return out;
}

function applyFilter(canvas, name) {
  if (name === 'original') {
    const c = document.createElement('canvas'); c.width = canvas.width; c.height = canvas.height;
    c.getContext('2d').drawImage(canvas, 0, 0);
    return c;
  }
  try {
    return withMats((track) => {
      const src = track(cv.imread(canvas));
      const fn = name === 'gray' ? fGray : name === 'bw' ? fBw : fAuto;
      const out = fn(src, track);
      return _canvasOut(out, canvas.width, canvas.height);
    });
  } catch (e) {
    console.warn('filter failed, fallback original', name, e);
    const c = document.createElement('canvas'); c.width = canvas.width; c.height = canvas.height;
    c.getContext('2d').drawImage(canvas, 0, 0);
    return c;
  }
}
```
