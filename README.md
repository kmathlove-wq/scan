# 스캔 (Scan)

종이·문서를 카메라로 찍으면 자동으로 네 모서리를 인식해 배경을 잘라내고 반듯하게 펴는 웹 앱.
필터를 골라 이미지(PNG·JPG) 또는 PDF로 저장한다. 서버 없음 — 사진은 내 기기 안에서만 처리된다.

- 주소: https://kmathlove-wq.github.io/scan/
- 설계 문서: `docs/superpowers/specs/2026-09-07-스캔-design.md`

## 개발 상태

준비 중 — 설계 확정 단계.

## 깃허브 페이지 켜는 법 (이미 켜져 있으면 넘어가기)

1. 깃허브 저장소 → **Settings** → 왼쪽 **Pages**
2. **Source**: "Deploy from a branch"
3. **Branch**: `main`, 폴더 `/ (root)` → **Save**
4. 1~2분 뒤 위 주소로 접속

## 수동 테스트 체크리스트 (배포 후 폰에서)

- [ ] 아이폰 사파리: 카메라 열림 / 실시간 파란 테두리 / 촬영 / 모서리 드래그 / 흑백 필터 / PDF 저장
- [ ] 안드로이드 크롬: 위와 동일
- [ ] 카메라 거부 시 "사진 파일 고르기"로 동작
